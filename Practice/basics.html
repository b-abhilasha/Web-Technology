About HTML

HTML stands for Hyper Text Markup Language, which describes the structure of web pages. It comprises the building blocks of all websites and uses markup tags to describe the format and layout of contents in a webpage. Therefore, HTML is a markup language. It consists of a series of elements.

Types of Elements

An HTML element is defined by a start tag, some content, and an end tag. They are either block-level or inline elements.
Block-level elements, such as paragraph tag and division tag, always start on new lines, and occupy the full width of their container.
Inline elements, such as anchor tag and span tag, do not start on a new line, and only take up as much width as their content needs.

HTML Tags

HTML is a tag based language. A tag is a piece of code that instructs a web browser what to display and how to display.The types of HTML tags are container tag (has both opening and closing tag) and empty tag (used by itself). HTML, HEAD, TITLE and BODY are basic tags.

Attributes of HTML Tags

Attributes provide additional information about HTML elements. A tag may have one or more attributes. An attribute is included within either a starting tag or an empty tag, and it consists of two parts: attribute name and its value.
Some commonly used attributes are background-color, style, href, width, height, etc.
